# WoW — Q&A workspace

This is not a code project. It's a Q&A workspace for World of Warcraft questions.

**Game version: WoW Forever** <!-- /wow-waypoint:init fills this in: WoW Forever, Classic Era, Hardcore, Season of Discovery, Cata/MoP Classic, or Retail -->
Answer from that version's rules. For WoW Forever, Classic Era, Hardcore and SoD that means Classic knowledge; search only for what that version changed. For Retail, never use Classic facts.

## How to answer questions

- **For general questions, answer from knowledge of the version above without searching.** That covers NPC and trainer locations, quests, zones, class basics, dungeons, and so on.
- **Search the web only when the question is about something new or changed in this version** (for Forever: new systems, items, zones, patch notes and hotfixes, release or server info). Also search for current routes or meta, or when unsure.
- When a base-game answer might plausibly be affected by a version change, mention it in one short line. Don't research it unless asked.
- Prefer recent sources, point out when sources disagree, and cite links for drop rates, quest steps, builds, patch changes and dates.
- Keep answers practical and direct.

## My characters

Tracked by the `wow-waypoint` plugin (set up with `/wow-waypoint:init`; character data comes from the armory site, which updates when I log out). Per-character files are in `notes/characters/<slug>/`, and my profile is in `notes/profile.md`. Skills: `track` (commands, live activity log), `recap`, `plan`, `instance` (role briefing before a dungeon or raid), `party` (me + friends), `dashboard`.

## Tracking questions (notes/)

- **Before answering**, check `notes/` for an existing answer and build on it. Refresh it if it looks stale.
- **After answering** a substantive question (routes, builds, guides, mechanics), save it to `notes/<topic>.md`, grouped as `## Q: ...` sections, e.g. `notes/herbalism.md`, `notes/classes/mage.md`.
- Each topic file starts with `_Last updated: YYYY-MM-DD_`, and each section ends with its sources. Mark anything unverified.
- Skip quick throwaway questions.
